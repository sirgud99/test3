# Qwen2.5 on WikiText-103

A readable, single-file pipeline for causal language-model fine-tuning and
post-training Koopman analysis with PyTorch, Hugging Face, NoRaRe, spaCy, and
Weights & Biases. It includes a quick Apple Silicon smoke run, a meaningful
local 0.5B run, and a full CUDA profile with Qwen2.5-3B.

## Files

```text
main.py           Complete active training and analysis pipeline
finetune_1.py     Frozen copy of the first validated fine-tuning pipeline
requirements.txt  Direct Python dependencies
.gitignore        Local data, models, checkpoints, credentials, and caches
README.md         Setup, commands, assumptions, and function reference
```

Everything generated by the pipeline is stored under the ignored `artifacts/`
directory. W&B's local state is stored under the ignored `wandb/` directory.

## Setup

This Mac has Python 3.9 installed, but the project requires Python 3.11 or newer.
Install Python 3.11 using your preferred package manager, then run:

```bash
python3.11 -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
wandb login
```

The models and dataset are public, so Hugging Face login is optional. Use
`hf auth login` if your environment requires authentication.

## Quick Mac smoke run

```bash
python main.py smoke
```

This command uses Apple MPS to download Qwen2.5-0.5B and WikiText-103, prepare
256 training blocks plus 64 validation and test blocks, fully fine-tune for 10
steps, and compare the untouched and fine-tuned models. A successful run:

- completes all 10 optimizer steps with finite loss and gradient metrics;
- writes `artifacts/smoke/results.json`;
- reloads the model saved at `artifacts/smoke/final/` before final evaluation;
- creates a W&B run tagged `smoke` without uploading model checkpoints.

## Real Mac run

For a meaningful local 0.5B experiment on the Mac, run one epoch over 10,000
training blocks with 1,000 validation and test blocks:

```bash
python main.py all --profile mac
```

This profile reuses the smoke model download, trains with MPS batch size 8, and
writes its independent checkpoint and metrics under `artifacts/mac/`.

The first completed run used 10,000 training blocks for 1,250 steps. On 1,000
held-out test blocks, loss improved from 5.4979 to 5.1203, perplexity from
244.17 to 167.38, and next-token accuracy from 20.29% to 23.56%.

## Full 3B run

Run each stage separately:

```bash
python main.py download --profile full
python main.py prepare --profile full
python main.py train --profile full
```

Or run the entire pipeline:

```bash
python main.py all --profile full
```

The full profile requires a CUDA GPU with BF16 support. Its defaults are one
epoch, batch size 16, gradient accumulation 16, learning rate `2e-5`, cosine
decay, 3% warmup, and full-parameter training. Useful overrides include:

```bash
python main.py train --profile full --batch-size 8 --gradient-accumulation 32
python main.py train --profile full --epochs 0.25 --run-name first-quarter-run
```

Evaluate an existing final model or a specific checkpoint:

```bash
python main.py evaluate --profile full
python main.py evaluate --profile full --checkpoint artifacts/full/checkpoints/checkpoint-1000
```

## Data preparation

The code follows Hugging Face's causal-language-model recipe for the raw
`Salesforce/wikitext` `wikitext-103-raw-v1` split:

1. Tokenize the `text` column with the selected Qwen tokenizer.
2. Concatenate token IDs within preprocessing batches.
3. Drop the incomplete remainder.
4. Split into non-overlapping 10-token blocks (stride 10).
5. Copy `input_ids` to `labels`.

The model applies the causal shift internally, so every block supplies nine
next-token predictions. Train, validation, and test splits remain separate.

## Post-training analysis

Run the complete analysis on the saved Mac checkpoint:

```bash
python main.py analyze --profile mac
```

The default uses 1,000 overlapping source windows, rank 64, and ridge penalty
`1e-3`. For a quick executable check:

```bash
python main.py analyze --profile mac --analysis-samples 32 --koopman-rank 8
```

The stages can also be run separately:

```bash
python main.py pairs --profile mac
python main.py annotate --profile mac
python main.py koopman --profile mac
```

`pairs` forms a 10-token source `x[t:t+10]`. Its ground-truth target is
`x[t+1:t+11]`; its predicted target is `x[t+1:t+10]` plus the model's argmax
next token. Successive source windows start one token apart by default. Each
pair records the full-vocabulary next-token entropy, true-token surprisal,
actual argmax token, and whether the prediction is correct. The final-token
hidden states from the last, penultimate, and antepenultimate transformer
layers are stored for the source and both targets.

`annotate` produces a long dataframe with two rows per pair: one ground-truth
target utterance and one predicted target utterance. It includes:

- last-word surface form, lemma, character length, numeric/alphabetic flags;
- POS, content/function class, and proper/common/not-noun class from spaCy;
- exact-form NoRaRe frequency, concreteness, iconicity, age of acquisition,
  valence, arousal, and dominance ratings;
- maximum spaCy dependency length;
- utterance means and coverage for every NoRaRe variable;
- the model entropy, surprisal, argmax prediction, and correctness fields.

The selected NoRaRe variables are SUBTLEX-US frequency (Brysbaert 2009),
Brysbaert 2014 concreteness, Winter 2024 iconicity, Kuperman 2012 age of
acquisition, and Warriner 2013 valence/arousal/dominance. The pipeline downloads
the public [NoRaRe CLDF release](https://github.com/concepticon/norare-cldf).
NoRaRe values are never fabricated: unmatched words remain missing, receive
missingness indicators during regression, and are summarized in
`feature_coverage.json`.

`koopman` fits six matrices: three layers crossed with ground-truth versus
predicted transitions. For each layer, the source hidden states define a
rank-limited POD/SVD basis. Ridge regression then estimates `Y = X K` in that
basis. Every eigenmode's absolute utterance alignment is regressed on the
standardized feature dataframe. The output includes every coefficient, R²,
eigenvalue, and the most-aligned utterances—not only selected significant
results.

Effective dimension is reported three ways:

- singular-value participation ratio, `(sum(s))² / sum(s²)`;
- stable rank, `sum(s²) / max(s)²`;
- numerical matrix rank.

### Analysis assumptions

- Qwen predicts subword tokens, not linguistic words. Entropy, surprisal, and
  argmax therefore refer to the next Qwen token. spaCy is applied to the
  decoded target string for word-level features.
- The "last word" is the last decoded spaCy token containing a letter or
  number. A predicted subword fragment can consequently have missing NoRaRe
  ratings.
- A raw layer weight matrix is constant across utterances and cannot define
  paired observations for regression. Here the lifting observable is
  `g_l(x) = h_l(x; W_l)`: the final-token hidden representation generated by
  layer `l` using its learned weights. This is the utterance-dependent quantity
  to which Koopman regression can be applied.
- Feature-to-mode regressions are descriptive in-sample ridge regressions. They
  identify associations, not causal effects or inferential significance.
- Rank 64 is a computationally tractable reduced-order model. Increase
  `--koopman-rank` only when sample count and hardware justify it.

## W&B and outputs

Training requires an authenticated online W&B session and logs configuration,
hardware, losses, gradient norm, baseline metrics, final metrics, and changes.
`WANDB_LOG_MODEL=false` is enforced, so model and checkpoint files stay local.

```text
artifacts/
  models/{smoke,full}/       Downloaded Hugging Face models
  data/wikitext-103-raw/     Raw dataset
  data/processed-{profile}/  Tokenized 10-token blocks
  norare/                    Downloaded CLDF tables and English lexical index
  {profile}/checkpoints/     Local resumable checkpoints
  {profile}/final/           Reload-tested final model
  {profile}/results.json     Baseline, validation, final, and delta metrics
  {profile}/analysis/
    utterance_pairs.csv      True and predicted shifted pairs
    utterance_features.csv   One annotated utterance per row
    representations.npz      Nine hidden-state arrays
    K_*.npy                  Six fitted Koopman matrices
    eigenmode_*.csv          Mode regressions, coefficients, and utterances
    eigenmodes_*.png         Six spectrum/alignment/coefficient plots
    effective_dimensions.png
```

## Function reference

- `parse_args()` defines the training and analysis commands and overrides.
- `download()` downloads one model profile and the shared raw dataset.
- `tokenize_batch()` applies the exact tokenizer paired with the model.
- `group_tokens()` concatenates token IDs and creates 10-token causal blocks.
- `prepare()` processes, verifies, limits, and saves all three dataset splits.
- `load_assets()` validates the accelerator and loads model, tokenizer, and data.
- `compute_metrics()` computes next-token accuracy after the causal shift.
- `evaluate_model()` evaluates loss and accuracy and derives perplexity.
- `train()` evaluates the baseline, trains, saves, reloads, and evaluates again.
- `smoke()` applies the fixed 0.5B MPS settings and runs the complete pipeline.
- `download_norare()` downloads the public CLDF annotation tables.
- `construct_pairs()` creates both shifted targets and extracts hidden states.
- `load_norare()` joins the selected English lexical variables by exact form.
- `annotate()` builds the utterance-by-feature dataframe with spaCy and NoRaRe.
- `feature_matrix()` imputes missing ratings and standardizes regression inputs.
- `fit_koopman()` fits one reduced ridge operator and computes its spectrum.
- `plot_koopman()` plots all modes, their alignments, and feature coefficients.
- `koopman()` creates six operators and regresses every eigenmode on features.
- `analyze()` runs the full post-training analysis in order.
- `main()` dispatches the requested command.
